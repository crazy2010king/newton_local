# Newton 物理引擎概述

## 什么是 Newton
Newton 是一款基于 NVIDIA Warp 构建的 GPU 加速物理仿真引擎，专门面向机器人专家和仿真研究人员设计。它扩展并泛化了 Warp 已弃用的 `warp.sim` 模块，并集成了 MuJoCo Warp 作为主要后端，强调基于 GPU 的计算、OpenUSD 支持、可微性和用户定义的可扩展性，便于快速迭代和可扩展的机器人仿真。

Newton 是 Linux Foundation 项目，由社区构建和维护。代码采用 Apache-2.0 许可证，文档采用 CC-BY-4.0 许可证。该项目由迪士尼研究院、Google DeepMind 和 NVIDIA 共同发起。

## 核心特性

### 🚀 GPU 原生加速
- 全栈 GPU 加速，从物理求解到渲染全流程在 GPU 上执行
- 支持 CUDA 12/13，充分发挥 NVIDIA GPU
- 针对 Ada Lovelace 和 Hopper 架构优化
- 单 GPU 即可支持数百万粒子实时仿真

### 🔍 可微仿真
- 原生支持可微物理
- 支持梯度反向传播
- 可与 PyTorch、JAX 等深度学习框架无缝集成
- 适用于机器人控制、策略优化、系统识别等场景

### 📦 OpenUSD 原生支持
- 支持 USD 场景导入导出
- 兼容 USD 物理材质和属性
- 支持大规模场景编辑和资产管理
- 便于与其他 DCC 工具集成

### 🧩 高度可扩展
- 模块化设计，支持自定义碰撞检测、求解器和材料模型
- 支持用户自定义内核扩展
- 插件式架构，便于添加新功能

### 🤖 机器人友好
- 原生支持 URDF、MJCF 格式导入
- 丰富的传感器模型（摄像头、IMU、接触传感器等
- 支持强化学习环境创建
- 兼容主流机器人框架集成

## 系统架构
```

├───────────────────────────────────────────────────────────┬─────────┤

├─────────────┼─────────────┼──────────┼──────────┼─────────┤
│                     Warp 运行时                        │
├───────────────────────────────────────────────────────────┤
│                     CUDA / CPU                          │
└───────────────────────────────────────────────────────────┘
```

### 核心模块

#### 1. 几何模块 (`newton.geometry`)
- 基础几何类型：球体、盒子、胶囊、平面、网格、高度场等
- 碰撞检测系统，支持连续碰撞检测 (CCD)
- 网格处理工具：简化、凸分解、SDF 生成等

#### 2. 仿真模块 (`newton.sim`)
- 刚体动力学
- 关节模型：6 DoF 关节、滑动关节、旋转关节等
- 材料模型：摩擦、 restitution、粘附等
- 约束系统：接触约束、关节约束、自定义约束

#### 3. 求解器模块 (`newton.solvers`)
- 基于 Projected Gauss-Seidel (PGS) 求解器
- 基于 XPBD 求解器
- 可微求解器
- 支持自定义求解器扩展

#### 4. 传感器模块 (`newton.sensors`)
- 接触传感器
- IMU 传感器
- 摄像头传感器（RGB、深度、分割）
- 力/力矩传感器

#### 5. USD 模块 (`newton.usd`)
- USD 场景导入导出
- USD 物理材质映射
- USD 阶段编辑 API

## 核心概念

### 模型 (Model)
仿真场景的静态表示，包含所有物体、关节、材料等
通常只构建完成后不可变，多个
可以被多个 世界 (World) 实例共享。

### 世界 (World)
仿真的动态实例，包含所有状态（位置、速度等)
运行时可变，支持多世界并行仿真。

### 状态 (State)
包含世界的完整状态快照，可用于保存/恢复仿真状态。

### 步 (Step)
执行一次仿真迭代，更新世界状态。

## 支持的仿真类型

### 1. 刚体仿真
- 支持任意形状的刚体
- 支持关节链、树结构、闭环机构
- 支持铰接体 (Articulation) 高效求解

### 2. 线缆仿真
- PBD 线缆模型
- 支持大变形、弯曲、扭转
- 支持绳索、线缆束仿真

### 3. 布料仿真
- 三角形网格仿真
- 支持各向异性材料
- 支持撕裂、切割

### 4. 软体仿真
- 四面体网格软体
- FEM 有限元模型
- 支持可变形体仿真

### 5. MPM 物质点法
- 流体、颗粒、固体统一建模
- 支持多材料耦合
- 适合复杂物理仿真

### 6. 多物理场耦合
- 刚体-流体耦合
- 刚体-布料-软体耦合
- 多物理场统一求解
